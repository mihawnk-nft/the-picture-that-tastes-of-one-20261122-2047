A stack of four golden pancakes drowned in glossy maple syrup — with
syrup dripping down the sides, a pat of butter melting on top, and thin
steam wisps rising. One look, one ingredient you can taste: maple syrup.

The image (`entry.png`, 1024×1024) is drawn procedurally with pure
Python standard library code (see `render.py` in the build directory);
`main.py` copies it to the output directory, validating the PNG magic
bytes and the 1 MiB size cap first.
